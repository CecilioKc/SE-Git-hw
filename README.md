# SE-Git-hw 
This is a small Python project created to demonstrate the fundamental Git and GitHub workflow. The repository shows how to create and clone a repository, make commits, work on a feature branch, collaborate through pull requests, and track work with GitHub Issues.

## Project Objectives
- Configure Git and connect a local repository to GitHub.
- Create and commit a simple Python program.
- Develop a new feature on a separate branch.
- Open, review, and merge a pull request.
- Create, assign, resolve, and close GitHub Issues.
- Document the project and reflect on the learning experience.
